# GrowthOS

**Brunson × Gadzhi × Aditya Bayu Operating System — v4.0**

A venture builder operating system for digital marketing, content, and multi-channel ad campaigns. Combines Russell Brunson's funnel architecture, Imam Gadzhi's high-ticket psychology, and Aditya Bayu's battle-tested principles.

## What's Inside

- `SKILL.md` — The complete GrowthOS framework (Hermes skill format)
- **5 Commandments** — non-negotiable principles applied everywhere
- **Quarterly Hero Campaign** rhythm (Q1 Reset / Q2 Scale / Q3 System / Q4 Max)
- **6/3/1 Content Mix** (Attract / Engage / Convert)
- **Hero Content → Ads Harvesting Engine**
- **Universal Audience Leveling** (Lv1–Lv4) applied to Meta, Google, LinkedIn, Email, Offline
- **High-Ticket Value Ladder** + Lead Magnet filtering
- **4-Stage Conversion Engine** (PAS / HSO)

## The 5 Commandments

1. **Personal Experience First** — every message resonates with relevant personal experience.
2. **Lead Magnet = Filter** — lead magnets sort qualified leads, not just collect emails.
3. **Specific & High-Value Lead Magnet** — niche and problem-solving to raise lead quality.
4. **Reframe & Repackage** — differentiation is in *how* you say it, not *what* you say.
5. **Single-Minded Proposition → Topik → Hook (PAS/HSO)** — one message, 2-3 topics, 2-3 hook angles each.
